# PAN → GSTIN Lookup Tool

A clean, fast tool to find all GST registrations (GSTINs) linked to any PAN number.

## Features
- 🔍 Single PAN lookup
- 📊 Bulk upload via Excel/CSV
- ⬇️ Export results to Excel
- 🌐 Shows state, trade name & status for each GSTIN

## Live Demo
Deployed on Vercel — see the live link above.

## Usage
1. Enter a PAN number directly, or
2. Upload an Excel file with a column of PAN numbers
3. Click Lookup — results appear instantly

## Tech
Plain HTML/CSS/JS + SheetJS for Excel parsing. No backend required for the UI.
